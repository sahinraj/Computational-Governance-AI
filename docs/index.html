The problem

Autonomous agents increasingly act inside organizations bound by explicit rules. The rules live in natural-language policy documents; the agent's behavior is governed by prompts. Nothing guarantees the two agree.

Policy-as-code today (OPA/Rego, RBAC, ABAC) assumes a deterministic caller making a static, pre-declared request. Agents reason, choose actions at runtime, and delegate authority to other agents. This project defines and implements governance for that harder setting: deciding whether an intended action is permitted before it executes.

The decision function

Given a governance state S = (A, C, Γ, Δ, κ) and an intended action α = (actor, capability, params), compute a decision:

𝔾(S, α) → { Allow, Block, Escalate(role) }

subject to four properties, each of which is also a benchmark category and a safety theorem:

  • Rule soundness — Allow only if every applicable rule is satisfied under current context.
  • Delegation validity — delegated authority must be valid along the actor's chain at decision time.
  • Escalation totality — a failed escalate rule yields Escalate, a first-class outcome, not a failure.
  • Context currency — the decision reflects the current context, so the same action can decide differently later in the process.

What it looks like

Rules are written in a small declarative language. A Law in the syntax denotes a Rule in the formal model.

LAW-001
  capability: payment.send
  authority_level: >= 3
  constraint: amount <= 100
  requires_approval: FinanceLead
  on_violation: escalate
from governance import parse_laws, Actor, Action, Capability, Context

rules = parse_laws(open("policy.law").read())
action = Action(Actor("agent-1", authority_level=5),
                Capability("payment.send"), {"amount": 150})

rules[0].evaluate(action, Context())   # Result.VIOLATED

GovernanceBench v0.2 contains 30 canonical scenarios and 39 trace steps, with at least three scenarios per category. Phase 3 adds conformance, durable recovery, model assurance, quorum approvals, and a v0.3 CLI; the reference implementation scores 39/39 exact benchmark decisions.

The program

The reference implementation and initial benchmark now complete the first release. GovernanceBench is runtime-agnostic, with a reproducible static-baseline comparison and failure-containment harness. Later theory extends the frozen foundations rather than replacing them.
